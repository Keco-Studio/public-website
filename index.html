Install on Windows

Download and run the official setup file, then follow the installer. The current installer is unsigned, so Windows SmartScreen may show a warning. Confirm that the publisher file came from the official Keco Studio GitHub release before continuing.

Install on macOS

Choose the DMG matching your Mac chip, open it, and move Keco Studio to Applications. Current builds are ad-hoc signed but not notarized; use Finder Open or Privacy & Security's Open Anyway control if macOS blocks the first launch.

FAQ

Before and after you download

Public support channels
What is Keco Studio?

Keco Studio is a connected workbench for game design. It turns design into structured data and art, helps build a playable Godot slice, and evaluates the result against a fixed standard.

Who is Keco Studio for?

It is built for game designers, narrative teams, technical designers, and creators who need to move from decisions and data to something playable.

Which computer systems are supported?

Version v0.1.7 provides Windows x64 and macOS builds for Apple Silicon and Intel. Linux and mobile versions are not available yet.

What should I do if downloading or installation fails?

Download the file again from this page and verify that you selected the correct platform. Review the Windows SmartScreen or macOS first-launch guidance above before contacting support.

Do I need an account the first time I use it?

You do not need an account to download the installer. Keco Studio requires you to sign in or create an account when you first launch it.

Is project data stored locally or in the cloud?

The desktop application connects to the online Keco Studio service. Do not treat the current desktop shell as a local-only storage product.

How do I update or uninstall the client?

For the current release, download the newest stable installer from this page when an update is available. Use the standard Windows Apps or macOS Applications process to remove Keco Studio.

Where can I find release updates or support?

Release files and notes are published in the Keco Studio GitHub organization. You can also use the verified community channels in the footer.
